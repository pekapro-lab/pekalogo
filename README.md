# Pekalogo

Generador de logos 3D gratuito (Vite + React + Three.js). Sin APIs de pago.

```
npm i && npm run dev
```

Licencia AGPL-3.0.

## Tipografía

Texto 3D con Poppins Bold (SIL Open Font License 1.1, The Poppins Project Authors), convertida con `scripts/ttf2typeface.mjs`. Ver `fonts/OFL.txt`.
